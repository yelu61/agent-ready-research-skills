# Figure story prompt

Review the proposed figure as a scientific argument. For each panel state:

1. the single question it answers;
2. source data and statistical unit;
3. whether it is discovery, validation, sensitivity or illustration;
4. the conclusion supported;
5. the conclusion it cannot support;
6. redundancy with other panels;
7. required legend details and source-data file.

Recommend a minimal panel order and record selected versus alternative versions
in the figure manifest.
