# Tumor Ecosystem Mechanisms

Use this module for malignant, immune, stromal, endothelial, and spatial
interactions that may shape tumor behavior.

## Separate Four Questions

1. **Composition** — which populations change in relative or absolute abundance?
2. **State** — which programs change within a population?
3. **Association** — which populations, states, or neighborhoods co-occur?
4. **Function** — which interaction changes tumor or host behavior?

Do not answer a functional question with composition alone.

## Distinguish Intrinsic and Extrinsic Mechanisms

- Cell-intrinsic: genotype, epigenetic state, signaling, metabolism, stress,
  differentiation, plasticity.
- Cell-extrinsic: ligands, nutrients, matrix, oxygen, immune pressure,
  mechanical constraints, vascular access, therapy exposure.

Test whether the same malignant state persists across different ecosystems and
whether ecosystem changes precede, follow, or maintain it.

## Evaluate Interaction Evidence

| Observation | Maximum default interpretation |
| --- | --- |
| Ligand and receptor transcripts | candidate interaction |
| Replicated sender-receiver association | ecosystem association |
| Spatial proximity | opportunity for interaction |
| Receiver target program | signaling-consistent response |
| Protein or phospho evidence | stronger pathway engagement |
| Perturbation or blocking | functional contribution |
| Rescue or orthogonal validation | stronger mechanism support |

Expression-based communication is not physical contact, signaling flux, or
functional consequence.

## Tumor Immune Reasoning

Keep distinct:

- immune ignorance or low antigen visibility;
- physical exclusion;
- inadequate recruitment;
- dysfunction or exhaustion;
- suppressive myeloid or stromal states;
- antigen-presentation loss;
- clone-specific immune editing.

Similar low-effector phenotypes can arise through different mechanisms.

## Spatial and Sampling Boundaries

Review compartment, region, margin/core, lesion, biopsy depth, dissociation
bias, and matched-sample structure. A biopsy samples an ecosystem, not the
whole patient.

## Output

Return composition, state, association, and function as separate claims;
identify intrinsic and extrinsic alternatives; specify spatial, protein, or
perturbational evidence needed to support the proposed ecosystem mechanism.
