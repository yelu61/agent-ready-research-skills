# Tumorigenesis and Progression

Use this module for normal-to-precursor-to-malignant change, local progression,
invasion, metastasis, residual disease, dormancy, and recurrence.

## Decompose the Disease Course

```text
normal tissue
  -> susceptible field or state
  -> precursor lesion
  -> malignant transformation
  -> local progression
  -> invasion and dissemination
  -> metastatic colonization
  -> residual or dormant disease
  -> recurrence
```

Do not assume every project contains or can order all stages.

## Ask Stage-Specific Questions

- What is the cell of origin, and is a state of origin more plausible than a
  fixed lineage?
- Which alteration is initiating, permissive, selected, or merely associated?
- Which normal or precursor comparator is required?
- Does progression reflect clonal expansion, state transition, composition, or
  tissue sampling?
- Which evidence distinguishes invasion competence from an EMT-like program?
- Which evidence distinguishes dissemination from successful colonization?
- Does recurrence arise from residual clones, dormancy, renewed plasticity, or
  a new primary process?

## Match Evidence to the Claim

| Claim | Minimum useful evidence |
| --- | --- |
| Candidate cell or state of origin | normal/precursor comparison plus lineage, genomic, or perturbational support |
| Initiating event | temporal or clonal precedence and functional contribution |
| Progression program | replicated stage association plus temporal, spatial, or functional validation |
| Metastatic mechanism | paired primary/metastatic evidence plus lineage or genomic linkage and functional colonization |
| Dormancy or residual disease | longitudinal persistence and reactivation evidence |
| Recurrence mechanism | pre/post or residual/relapse linkage with clone and state resolution |

## Guard Against False Chronology

- Cross-sectional cohorts do not by themselves establish temporal order.
- Pseudotime is not tumor natural history.
- RNA velocity is not clonal ancestry.
- An EMT-like expression program is not proof of invasion or metastasis.
- Higher stage association is not necessarily a progression driver.
- A shared malignant state across patients is not shared clonal origin.

## Integrate Scales

Separate:

- genomic clone;
- epigenetic competence;
- transcriptional state;
- cell behavior;
- ecosystem constraint;
- anatomical dissemination;
- clinical stage.

Connect these scales only with explicit evidence.

## Output

Return the proposed disease stage, temporal assumptions, origin or progression
hypotheses, competing explanations, missing longitudinal or lineage evidence,
and the strongest claim supported by the available design.
