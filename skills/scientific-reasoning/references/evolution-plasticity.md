# Evolution and Plasticity

Use this module when a pattern could reflect genetic evolution, ecological
selection, reversible cell-state change, or several processes together.

## Keep Core Distinctions

| Dimension | Question |
| --- | --- |
| Clone versus state | Does genomic/lineage evidence define ancestry, and how do expression states vary within and across those lineages? |
| Selection versus induction | Was a pre-existing population enriched or was a new state produced? |
| Adaptation versus stable evolution | Does the state reverse after the pressure is removed? |
| Branching versus convergence | Do similar phenotypes arise from shared or independent lineages? |
| Genetic versus non-genetic resistance | Is resistance carried by genotype, regulatory memory, ecosystem, or combination? |
| Immune editing versus inflammation | Is immune pressure selecting clones or merely changing state and composition? |

A clone can contain several states; a state can occur in several clones.
Non-genetic states may be transient, metastable, or stably inherited through
epigenetic memory. A stable phenotype does not prove a new mutation, and lack
of rapid reversal does not by itself establish genetic evolution. Define the
observation/withdrawal timescale and measure both ancestry and state where the
distinction matters.

## Build Competing Models

For any pre/post or primary/metastatic difference, compare:

1. pre-existing clone selection;
2. pre-existing state selection;
3. induced reversible state;
4. newly acquired genetic change;
5. altered microenvironment or sampling;
6. technical or compositional artifact.

Do not choose among them from post-treatment enrichment alone.

## Discriminating Evidence

- paired genomic and transcriptomic profiles;
- longitudinal or dense time-course sampling;
- clonal barcodes, phylogeny, or lineage tracing;
- pre-treatment detection with adequate sensitivity;
- withdrawal and rechallenge;
- single-cell state-to-clone association;
- perturbation of the proposed state regulator;
- matched ecosystem and exposure measurements.

## Claim Boundaries

- State enrichment supports association with selection pressure.
- Shared clone-state association supports, but does not prove, heritability.
- Reversibility supports plastic adaptation.
- Phylogenetic linkage supports ancestry, not the functional cause of a state.
- Convergent programs suggest common selective pressure, not identical
  mechanism.
- Resistant residual cells are not automatically the cells that caused relapse.

## Output

Return the competing evolutionary models, evidence that distinguishes them,
clone-state uncertainty, reversibility requirements, falsifiers, and the
allowed wording for selection, induction, adaptation, and evolution.
